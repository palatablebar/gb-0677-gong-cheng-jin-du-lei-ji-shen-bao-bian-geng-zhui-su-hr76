# 计量定义

业务键为「分包商 + 申报编号」，不是申报编号单独唯一：申报编号由各分包商独立起编，两家都可能从 00001 开始。`party`（别名：分包商、申报单位）为可选列，缺失时记为「未标注」。`receipt_no`（别名：回单号、原始回单号）为可选列，缺失时按 `分包商/编号/源行` 生成稳定编号，保证逐条可回查。

claim_id 在分包商内唯一；item 为清单编码，支持钢筋与001等别名。period为YYYY-MM。累计数量按t或m³保存，当前周期工程量=本次累计-前期已审累计。previous_revisions参数可指定更正后的前审数量（键支持「分包商|编号」或纯编号），重新计算形成不同批次，不覆盖旧证据。

同号跨分包商：同一 claim_id 出现在不同 party 下时两行都参与计量，不视为重复。M1 `collisions` 记录共号编号、各方原始回单号与源行及裁决依据；M6/M7 按分包商分别给出合计。同方同编号取值冲突仍保留首到行、隔离后到行，并生成 `CF-xxx` 裁决记录。证据CSV的 `kind` 列区分 `accepted`、`quarantine`、`shared_number`、`conflict_basis`。

C0原始价100元，C1自2026-11生效为120元，DRAFT未批准不可结算。负进度必须reversal=approved作为已批冲回标记。扣留质保金5%、预付款扣回10%分别按分量化，净额=本期总额-质保金-预付款扣回，负进度同步冲回扣留。reported为原申报净额，差异=复算净额-reported。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
